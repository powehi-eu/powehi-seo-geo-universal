# GBP Description — Factual Draft

## Use This When

## Required Inputs

- verified business facts.
- services.
- service area.
- differentiators.
- prohibited claims.
- Constraints, exclusions, target market, and freshness requirements.

## Evidence Rules

Treat supplied measurements and primary sources as evidence; label observations, inferences, and assumptions separately. For this workflow, never invent missing data or convert an unsupported correlation into causation. Specifically verify every claim used to produire une description GBP factuelle et conforme. Record the source and observation date for volatile facts.
